## 八、报告与操作呈现规范（用户新增，2026-10-13）

> 适用于本项目全过程的操作指导。DSH 必须遵守，用户可据此核对。

| # | 规则 | 说明 |
| --- | --- | --- |
| **1** | **报告必须用代码块** | 给 GPT 指挥的报告全文置于单一代码块内，便于整段复制 |
| **2** | **用户操作必须用独立代码块** | 不得与报告块重合、不得混排 |
| **3** | **不可合并的步骤必须分块** | 一次操作一个代码块；能合并的用 `&&` 合并但需注明 |
| **4** | **每条操作必须标注终端** | 明确写「终端 A / B / C / D」或「新开终端」 |
| **5** | 报告块与操作块须有明显分隔 | 用 ①②③ 编号 + 加粗标题区分 |
| **6** | 终端标识须保持一致 | 沿用已建立的命名（A/B/C/D） |
| **7** | 用户操作块须标注批准依据 | 如「经 GPT-050 三节批准」 |
| **8** | **给任何人的文本都必须用代码块包裹** | 不区分对象，一律代码块 |
